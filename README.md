# Fresh People Book

Book event staff on WhatsApp — a take.app-style landing page for Fresh People
(Premier Talent & Events Staffing, Johannesburg / Randburg, Gauteng).

Clients browse bookable staff roles (Brand Ambassadors, Models & Hosts,
Hospitality, Event Logistics, Corporate Events, Weddings) and each one opens a
WhatsApp chat pre-filled with a structured booking message (date, times,
headcount, venue). No payments, no dashboard — a pure click-to-book landing page.

- Live: https://yassinAliYassin.github.io/fresh-people-book/
- WhatsApp: https://wa.me/27672961272

## Stack

- Single self-contained `index.html` (vanilla HTML + Tailwind CDN + Inter font)
- Deployed to GitHub Pages via GitHub Actions (no build step)

## Local preview

python3 -m http.server 8123 --bind 127.0.0.1
# open http://127.0.0.1:8123
